# Omniboss

One word for the human this agent works for: **Omniboss**. He is a hands-on owner running many small ventures at once, everywhere in the work at the same time, giving short direct orders and expecting them done without being asked twice — a boss who seems to be in all places at once. The word is a coined compound, funny and specific, and it lands on its own with no explanation.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt`.
